Frequently Asked Questions

Quick answers for common resident tasks.

What does my request status mean?

Pending: awaiting review. Under Review: being handled by the barangay. Approved: approved; check the instructions for next steps. Released: the document has been handed over. Rejected: read the reason in your request. Cancelled: the request is no longer active. Always check the latest staff remarks.

How do I upload missing documents?

Open My Request and select the affected request. Read the staff remarks, choose Submit Missing Documents when available, and attach the requested files. Follow the displayed file type and size limits, check that each file is readable, then submit. If the upload fails, check the file and try again.

Can I follow up or cancel a pending request?

Open the pending request in My Request. Use Follow up to send a clear message, or Cancel Pending Request if you no longer need it. Review the confirmation before cancelling. If an action is unavailable or you need to correct submitted details, contact the barangay rather than submitting a duplicate request.

Need more help?

For questions about requirements, a submitted request or collection, contact the barangay office.

Barangay office / portal administrator

Use the official contact channel published by your barangay, or ask at the barangay hall. For login or portal errors, ask to be referred to the portal administrator.

What to include?

Provide your request ID, a document name, submission date, and current status. Explain what happened, any error message and the steps you tried. For an upload issue, include the file type and size.

Hide sensitive details in screenshots. Never share your password or unnecessary identity documents.
