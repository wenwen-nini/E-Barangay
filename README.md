# E-Barangay
A Barangay Online Document Request and Records Management System, web-based platform designed to improve the way barangay offices handle document requests and manage resident records.

The backend allows the frontend origin from `FRONTEND_ORIGIN` for credentialed CORS requests. Set it to the frontend's full origin (scheme, hostname, and port), for example `https://barangay.example.com`. If unset, it defaults to `http://127.0.0.1:5500`.
